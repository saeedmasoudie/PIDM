# PIDM branding assets

Place your production logo at:

```text
assets/logo.png
```

Recommended source:

- Square PNG with transparency
- At least 256×256 pixels
- Keep important artwork away from the outer 10% safe area

PIDM automatically uses this file for the title bar, application windows,
system tray, and operating-system taskbar. If it is absent, PIDM uses its
generated fallback `P` icon.

The bundled `fonts/Vazirmatn[wght].ttf` is used automatically for Persian.
Its SIL Open Font License is included beside the font.
